# AXRYZURE THE HYSTORI COSMIC

Perpustakaan cerita kosmik interaktif berbasis web. Memuat kisah **ASMODEUS VS AZATOTH** dan fitur untuk menambah cerita, bab, serta mengedit teks.

## Fitur
- Login sederhana dengan nama pengguna
- Simpan cerita dan bab di localStorage
- Tambah, edit, hapus bab
- Tampilan responsif bertema kosmik
