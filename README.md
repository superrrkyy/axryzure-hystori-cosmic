 # AXRYZURE THE HYSTORI COSMIC

Perpustakaan cerita kosmik interaktif berbasis web. Menyimpan kisah-kisah epik tentang pertempuran antar entitas absolut, kehampaan, dan misteri di luar realitas. Pengguna dapat membaca, menambah, mengedit, dan menghapus cerita beserta bab-nya secara langsung di browser.

## Fitur

- **Login sederhana**: Masuk dengan nama penjelajah kosmik (tersimpan di localStorage).
- **Daftar cerita**: Menampilkan semua cerita dengan deskripsi singkat.
- **Pencarian**: Cari cerita berdasarkan judul atau deskripsi.
- **Tambah cerita**: Buat cerita baru dengan judul dan deskripsi.
- **Edit & hapus cerita**: Ubah judul/deskripsi atau hapus cerita beserta seluruh babnya.
- **Manajemen bab**: Tambah, edit, hapus bab dalam setiap cerita.
- **Pembaca**: Tampilan baca yang bersih dan fokus.
- **Penyimpanan lokal**: Semua data disimpan di `localStorage` browser, tanpa server.
- **Tema kosmik**: Desain gelap dengan aksen gradasi ungu-cyan, responsif di desktop dan mobile.

## Cerita Bawaan

Web ini sudah dilengkapi beberapa cerita contoh:

1. **ASMODEUS VS AZATOTH** – Perang di luar pemahaman antara keteraturan dan kekacauan.
2. **CHRONICLES OF THE VOID** – Perjalanan penjaga gerbang kosmik melintasi kehampaan.
3. **FALL OF THE PRIMORDIALS** – Kisah perang pertama para dewa pencipta.

Kamu bisa menambahkan cerita baru atau melanjutkan cerita yang sudah ada.

## Cara Menggunakan

1. Buka halaman web (`index.html`).
2. Login dengan nama apa saja.
3. Pilih cerita dari sidebar untuk membaca.
4. Gunakan tombol **+ Tambah Cerita** untuk membuat cerita baru.
5. Saat membuka cerita, klik **+ Tambah Bab** untuk menambahkan kelanjutan.
6. Setiap bab dan cerita dapat diedit atau dihapus.

## Instalasi Lokal

Cukup unduh file `index.html` dan buka di browser modern (Chrome, Firefox, Edge). Tidak perlu server atau dependensi tambahan.

## Deploy ke GitHub Pages

1. Buat repository di GitHub.
2. Upload file `index.html` ke repository (pastikan bernama `index.html`).
3. Buka **Settings → Pages**, pilih branch `main` dan folder `/ (root)`.
4. Simpan. Halaman akan tersedia di `https://username.github.io/nama-repo/`.
